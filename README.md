# Обгони отговорки — Drive Fitness

Браузерный 3D-раннер: беги к своей форме, обходи отговорки и не попадись Лени.

- **Неделя без отговорок** — 7 уровней от понедельника до воскресенья, с каждым днём сложнее.
- **Свободный забег** — бесконечный режим на рекорд.

Управление: стрелки / WASD на компьютере, свайпы на телефоне.

Играть: откройте `index.html` или страницу GitHub Pages этого репозитория.
